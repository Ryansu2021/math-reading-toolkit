# 數學閱讀理解工具包

國中數學「文字圖表應用題」的讀題訓練互動網頁，以「關係先行」為核心：學生先把量與量的關係找出來，再寫式子。

線上使用：https://ryansu2021.github.io/math-reading-toolkit/

## 為什麼
110–115 年會考 46 題情境選擇題，把錯誤選項反推到出錯步驟：選錯的基礎組學生有 54.7% 錯在「找關係」，而不是看不懂圖表或算錯。

## 內容
| 功能 | 說明 |
|---|---|
| 讀題四問 | 問什麼？要先知道什麼？條件管誰？真的用不到？ |
| 五步讀題 | 圈問題 → 拆資料 → 找關係 → 寫式子 → 回情境 |
| 從問題往回拆 | 由問的量拆出需求樹，資料因被需要才框起來 |
| 記號旁寫字 | 圈、框、底線、劃掉，旁邊都要寫字 |
| 三種模式 | 示範（放聲思考，可朗讀）／引導／自問 |
| 六題練習 | 改編自歷屆會考，附全國基礎組常見錯例與錯在哪一步 |
| 紙上挑戰 | 離開網頁讀一題，再對照專家讀法自我檢核 |
| 白板 | 可在畫面上畫記、橡皮擦、存圖 |

單一 HTML 檔，不需安裝，畫面隨螢幕大小自動縮放。
